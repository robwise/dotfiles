# Triage labels

| Role | Linear label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | More information needed |
| ready-for-agent | ready-for-agent | Fully specified for an agent |
| ready-for-human | ready-for-human | Human implementation needed |
| wontfix | wontfix | Will not be actioned |

Use these labels independently of Linear workflow statuses.
Preserve unrelated labels when changing triage state.
