# Issue tracker: Linear

Issues and specs live in the dotfiles project in the Personal team of
the Rob Wise Personal Development workspace.

Project: https://linear.app/robwise/project/dotfiles-345679245f18

Use the connected Linear tools to read and manage issues. Scope searches
and new issues to this team and project.

Create specs as issues in Backlog, with the spec in the description.
Apply triage labels using `triage-labels.md`. Read the description,
comments, labels, and relevant relations before working on a ticket.

Move implementation work to In Progress when it begins. Record the
result and validation in the issue, then mark it Done once its
acceptance criteria are satisfied.

When a skill says “publish to the issue tracker,” create a Linear issue.
When it says “fetch the relevant ticket,” read the referenced Linear
issue and its comments.
